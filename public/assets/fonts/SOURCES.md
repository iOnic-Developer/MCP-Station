# Plus Jakarta Sans

Self-hosted upright variable Latin subset, weights 200–800. Unmodified WOFF2 supplied
by Google Fonts; no remote fonts are requested by the application.

- Family: Plus Jakarta Sans
- Designers: Tokotype (https://tokotype.com)
- License: SIL Open Font License 1.1; see `plus-jakarta-sans-OFL.txt` alongside this file.
- Upstream: https://github.com/google/fonts/tree/main/ofl/plusjakartasans
- CSS source: https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@200..800&display=swap
- Latin binary: https://fonts.gstatic.com/s/plusjakartasans/v12/LDIoaomQNQcsA88c7O9yZ4KMCoOg4Ko20yw.woff2
- Retrieved: 2026-10-16
- WOFF2 SHA-256: `153fc85b70298beeb1d61a5f723331649e7f23bb77302a66e61cb3e2fbdb5e79`

`station-wordmark.svg` contains outlines derived from the upstream variable TTF at
weight 700. It needs no installed font and is usable as a standalone image. The
font license is retained with the font; the original symbol is project artwork.
