# Cloudflare Zero Trust & Tunnels

Manage Cloudflare Tunnels (cloudflared), ingress rules, Zero Trust Access applications, access policies, groups, service tokens, and DNS routing.

Bundled source only; configure your own credentials in Settings. No accounts or sessions are supplied.
Use least-privilege service credentials. Tools can read or modify data as permitted by those credentials.
Do not publish tool results containing private data, passwords or newly generated tokens.
